Page Snap Privacy Policy

Last updated: October 30, 2026 · Applies to Page Snap version 1.6 and later

In short: Page Snap keeps your screenshots, history and settings on your own computer. The developer does not receive any of it. The only time anything is sent anywhere is when you press the optional “AI title” button, and then only to Anthropic, using your own API key.

Who is responsible

Page Snap is published by Zakaria NEILI. Questions about this policy: zaki.neli@yahoo.fr.

What Page Snap does

Page Snap is a Chrome extension that captures screenshots of the web pages you are viewing, lets you annotate and save them, and keeps a history of what you saved. It works only when you ask it to: by pressing its keyboard shortcut or clicking its toolbar button, or, if you turn on the optional mouse gesture in the settings, by pressing the left and right mouse buttons together.

Information Page Snap handles

InformationWhat happens to it
Screenshots of pages you capture Shown in the editing window, then saved as a file in your Downloads folder when you press Save. If you keep the history turned on, a copy is stored in the extension's local database on your computer.
Titles, page addresses, notes and tags Stored with each saved capture in the local history, so you can search it. They stay on your computer.
Settings (folder name, file name pattern, image format, tool and color choices) Stored in the browser's extension storage on your computer.
Your Anthropic API key (optional) Stored in the browser's extension storage on your computer. It is used only as the credential in the request described below.
Mouse button presses on pages Only if you turn on the optional mouse gesture in the settings. Page Snap then asks your browser for access to all sites and watches mouse presses in pages only to detect the left-plus-right click. They are not recorded or stored. Turning the gesture off gives that access back.

A screenshot shows whatever is on your screen at that moment, which can include personal or sensitive information. Page Snap does not look for it or read it; you decide which pages to capture. The editor has Blur and Cover tools to hide details before you save, and a file you save to Downloads is an ordinary file that you control.

The one case where data leaves your computer: AI title

If you add your own Anthropic API key and press AI title, Page Snap sends the following to Anthropic’s API (api.anthropic.com) so that Claude can write a short title for the capture:

  • the page’s title, description and main heading, and the first 1,500 characters of its text;
  • your API key, as the credential for the request.

Screenshots are never sent. Nothing is sent unless you press the button, and the first time you do, Page Snap asks for your confirmation. The developer of Page Snap does not receive this data. Anthropic handles it under its own terms and privacy policy, which you can read on anthropic.com. If you never add an API key, this feature never runs.

What Page Snap does not do

  • It does not sell your data, show ads, or use analytics or tracking of any kind.
  • It does not require an account.
  • It does not send data to the developer or to any server other than the Anthropic request above.
  • It does not download or run code from the internet; everything it runs is included in the extension.

Your choices and control

  • Delete any capture from the history, or delete the whole history, on the history page or in the settings.
  • Turn off the history in the settings so that captures are not kept after saving.
  • Remove your API key in the settings at any time.
  • Uninstalling Page Snap removes its stored data from the browser. Files you saved to Downloads stay where they are until you delete them.

Because the developer never receives your data, there is nothing on the developer’s side to access, correct or erase.

Security

Data is kept in your browser profile. Your API key is stored in the browser’s extension storage, so anyone who can use your computer account and browser profile could read it. Use a key with a spending limit, and remove it from the settings if you share the computer.

Chrome Web Store User Data Policy

Page Snap’s use of information it handles follows the Chrome Web Store User Data Policy (explained in Google’s User Data FAQ), including the Limited Use requirements. Page Snap uses the information only to provide its single purpose: capturing, annotating, saving and looking back at screenshots. It does not transfer it to others except as described above, and does not use it for advertising, creditworthiness or lending.

Children

Page Snap is not directed at children under 13 and does not knowingly collect information from them.

Changes to this policy

If Page Snap’s handling of data changes (for example, a new feature that contacts a server), this page will be updated before the change ships, and the date at the top will change.
